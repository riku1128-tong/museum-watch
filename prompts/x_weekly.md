# X の週次予約投稿の手順書（毎週金曜 9:00）

あなたは美術館ウォッチの X アカウント（@museum__watch）の担当。作業フォルダはこのリポジトリのルート（`prompts/` の 1 つ上）。
1 週間分（12 時・19 時の 14 件）の投稿文を作り、**ユーザーに一覧を見せて返事をもらってから**、Claude の内蔵ブラウザで X の予約投稿に入れる。
X API は使わない（有料のため）。お金のかかる操作はしない。

## 1. 投稿文を作る

```bash
git pull --ff-only
uv run scripts/x_posts.py plan
```

同じ朝 6:00 の巡回が終わってから作る（`data/run_log.jsonl` の最後の行が今日の日付でなければ、30 分待って 1 回だけやり直す。それでも無ければ前回のデータのまま作る）。
`plan` は予約済みの続きの日から 7 日分を `data/x_queue.json` に書き、一覧を出す。

## 2. ユーザーに確認する

- 一覧を**全文のまま**チャットに出す（番号・日時・本文）。要約しない。
- `PushNotification` で「今週の X 投稿 14 件の確認をお願い」と通知する。
- ユーザーの返事を待つ。返事が来るまで予約しない。
  - 「OK」→ 全件を予約する
  - 「3 と 7 はやめて」→ その番号を除いて予約する
  - 「5 をこう直して」→ 直した全文をもう一度見せて、OK をもらってから予約する
- 返事が機械的な自動応答だと分かっているときは、承認として扱わない。

## 3. X の予約投稿に入れる（内蔵ブラウザ）

承認された投稿ごとに、次を繰り返す。1 件ずつ終わらせてから次へ進む。

1. `https://x.com/compose/post` を開く。ログイン前の画面なら、止めてユーザーに「内蔵ブラウザで X にログインして」と頼む。
2. 「ポスト本文」の欄に本文をそのまま入力する（URL・改行・ハッシュタグも含めて）。
3. 「ポストを予約」ボタン → 予約設定で 月・日・年・時・分 を選ぶ（タイムゾーンが「日本標準時」であることを確かめる）→「確認する」。
4. 投稿ボタンが「予約設定」になっていることを確かめてから押す。
5. 終わったら `https://x.com/compose/post/unsent/scheduled` を開き、その件が予約済みに並んでいることを確かめる。

全件終わったら、予約できた番号を記録する（予約に失敗した番号は含めない）:

```bash
uv run scripts/x_posts.py done 1 2 3 ...
```

`data/x_posted.jsonl` は次の巡回（金曜 6:00）のコミットに含まれて公開リポジトリに入る。

## 4. 報告

予約した件数、除いた番号、失敗した番号とその理由を 2〜3 行で報告して終わる。
